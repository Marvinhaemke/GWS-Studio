GWS Studio mit Frame.io V4 API-Review

Start (Node.js24+):
1. .env.example nach .env kopieren.
2. npm start
3. Die ausgegebene lokale Adresse im Browser öffnen.

Keine npm-Abhängigkeiten erforderlich. Für echte Frame.io-Daten sind die eigenen Adobe-OAuth-Zugangsdaten, ein HTTPS-Callback und eine Anmeldung notwendig.

Siehe README.md und FRAMEIO-SETUP.md für Einrichtung, Hosting, Datenbank und optionale Webhooks. Die HTML-Einzeldatei dient nur zur Ansicht der Oberfläche.
